Saving and moving progress

Checking where progress is saved…

On your computer, run the save server from the repo folder. Every answer is written to results/ and results/REPORT.md is rebuilt:

python serve.py

To move progress between the hosted version and the repo, export everything as one file here, then import it on the other side. When both have progress for the same course or quiz, the most recently saved one wins.
