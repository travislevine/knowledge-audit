# MiniBank security findings

Write up each vulnerability as you would for a real security report: short
and specific, so a developer who has never seen it could understand and fix
it. One example is filled in for format.

## Example: (format reference)

- **Where:** `app.py`, function name and line
- **Type:** the category (for example SQL injection)
- **How to exploit it:** the exact input or request, step by step
- **Impact:** what an attacker gains, and who is affected
- **Fix:** what you changed, and why it works
- **Severity:** low / medium / high / critical, with one line of reasoning
